# Contributing

Bug reports and ideas are welcome on the [issue page](https://github.com/StarHug/anki-sheets/issues).

## Code contributions

By sending a pull request or patch you confirm that:

1. You wrote the contribution, or have the right to submit it.
2. You license it to the project under the same terms as the rest of the code (AGPL-3.0-or-later with the additional terms in `LICENSE`).
3. You also give the copyright holder of IchiSheet a perpetual, worldwide, royalty-free right to use, modify and relicense your contribution as part of IchiSheet, including under other licence terms.

Point 3 keeps the project able to change its licence or offer other versions later without having to track down every contributor.

The StarHug and IchiSheet names, logos and images are not open for reuse; see `LICENSE`.
